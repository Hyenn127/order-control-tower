# AI Order Control Tower

발주 이상 탐지 관제 화면 프로토타입. 단일 HTML 파일이며 빌드 과정이 없습니다.

## 실행

정적 파일이라 웹서버에 올리기만 하면 됩니다. 로컬에서 볼 때는:

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 으로 접속합니다.

> 파일을 더블클릭해 `file://` 로 열면 지도 API 인증이 거부됩니다. 반드시 HTTP 로 접속하세요.
> 지도가 인증에 실패하면 화면이 깨지지 않고 권역 집계 표시로 자동 전환됩니다.

## 지도 설정

네이버 지도 Web Dynamic Map 을 사용합니다. `index.html` 상단의 `NAVER_MAP_KEY` 에
NAVER Cloud Platform 에서 발급한 Client ID 를 넣고, 콘솔의 **Web 서비스 URL** 에
배포 도메인을 등록해야 합니다. 포트와 경로는 빼고 호스트만 등록합니다.

## 데모 데이터

화면의 발주·대리점·품목 정보는 전부 데모용으로 구성한 가상 데이터입니다.

## 자체 점검

브라우저 콘솔에 데이터 정합성 점검 결과가 출력됩니다.
판정 기준이나 집계가 어긋나면 `[SELF-CHECK 실패]` 로 즉시 드러납니다.
